# omo-coworkers

`omo-coworkers` **7.0.0** 是面向 OpenChamber 2.8.0 及以上版本的扩展。能力面板面向手机、平板和桌面：窄窗口显示能力列表与单项详情，宽窗口显示列表和详情双栏。它替代 6.x 的通用配置编辑器，不提供任意配置、提示词或用户配方编辑。

## 能力与边界

- **项目角色**：`document-writer` 和 `lark-operator` 可在来源可安全解析时调整配置启用状态、模型和思考等级（variant）。原生 OMO 配置是唯一权威；复杂 preset 继承或模型链保持只读。启用配置不代表运行中已加载。
- **项目指导**：协作、Claude 和 Antigravity 指导提供显式采用或更新项目内容，不是内建代理或 ACP 服务的启停开关。ACP `permissionMode` 是权限，不是启停。
- **项目标准内容**：提示词、路由和声明依赖由项目维护。安装或普通模型保存不会自动覆盖个人提示词；采用项目标准需单独确认、预览并保存。可识别的内联覆盖需明确同意替换；无法安全解析的覆盖会阻止采用。个人模型、额外 Skills/MCP 与凭据保留。
- **依赖状态未确认**：清单中 `document-writer` 必需 `maintaining-product-engineering-docs`，`domain-modeling` 和 `humanizer` 为可选；项目随包提供这三项技能。Lark 外部依赖仍未完整确定，面板不自动安装第三方组件或配置凭据。
- **模型目录**：宿主服务通过固定的 `opencode models` 和 `opencode api GET /api/model` 读取模型 ID 与可用 variant；来源始终标为未验证，不能证明目录来自当前托管实例或模型可调用。保留未知现有值，不猜测等级。

内容采用及角色设置各自经预览、确认和有限事务保存；最近十次变更可条件撤销，无时间期限但受容量限制。旧通用编辑、揭露和用户配方 API 已退役，旧历史和未完成事务仍按兼容规则处理。

服务 `runtime: "host"` 拥有当前用户的完整 Node 权限，**不是沙箱**。扩展安装、服务授权、显式保存、手动重载和运行态核验是不同步骤；安装更新不会自动改写原生 OMO 文件，保存也不代表当前会话已生效。

详细操作、升级和恢复见 [INSTALL.md](INSTALL.md)；来源与历史见 [SOURCES.md](SOURCES.md)。
